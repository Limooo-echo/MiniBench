# CCPD source subset

These original PGN bytes are from [Chinese Chess Practical Dataset](https://github.com/Yvonne761/Chinese-Chess-Practical-Dataset), by Yvonne761, revision `368a47a947773dd8692c026e286dd19b6277b993`, under CC-BY-4.0. No chess moves or text were modified. MiniBench selects positions from them and records each original relative path and SHA-256 in `source_manifest.json`.

This small subset allows the independent release gate to replay the C2 source games. It is not the full candidate-mining pool.
